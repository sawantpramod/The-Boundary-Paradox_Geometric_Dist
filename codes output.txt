----------------------------------------------------------------------
STATISTICAL POWER CAVEAT
----------------------------------------------------------------------
The chi-square tests within each group have only 2-3 degrees of freedom
(compared to 6 in the pooled test), with roughly one-third the sample size.
Tests with this level of power will fail to reject the null unless the
effect is quite large.

The 'not rejected' finding should be read as:
  'The data are consistent with the geometric model within groups,'
  NOT as definitive proof of geometric behavior.

----------------------------------------------------------------------
CIRCULARITY CAVEAT
----------------------------------------------------------------------
The stratification variable - each innings' own realized boundary rate -
is partly determined by the same events (including the first boundary itself)
that the outcome variable is built from.

An innings that gets an early boundary mechanically nudges its own 'rate'
upward, which could bias groups toward looking more internally consistent
than an independent proxy (ground, opposition attack, team aggression profile)
would.

A stronger test would use pre-match covariates rather than post-hoc realized rates.
